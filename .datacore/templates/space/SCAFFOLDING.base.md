# Organization Scaffolding

> The cognitive architecture of a self-learning organization.

**Version**: 1.1
**Pattern**: DIP-0003

---

## Overview

This scaffolding defines the foundational documents every organization needs to operate effectively with AI agents. It serves as:

1. **Checklist** - What documents should exist
2. **Structure** - Where documents should live
3. **Status Tracker** - What's complete vs. missing
4. **Contribution Guide** - How to add new document types

### Layered Structure

Per DIP-0002, scaffolding uses layers:

| File | Layer | Purpose |
|------|-------|---------|
| `SCAFFOLDING.base.md` | PUBLIC | This template (upstream) |
| `SCAFFOLDING.space.md` | SPACE | Space-specific additions & status |
| `SCAFFOLDING.local.md` | PRIVATE | Personal notes (gitignored) |
| `SCAFFOLDING.md` | Composed | Generated output (gitignored) |

### Document Status Values

| Status | Meaning |
|--------|---------|
| `missing` | Document doesn't exist |
| `stub` | Placeholder generated by agent |
| `draft` | Content exists, needs review |
| `reviewed` | Human-reviewed, not final |
| `published` | Complete and approved |

## AGENTS

Agents that maintain the scaffolding:

| Agent | Purpose | Schedule |
|-------|---------|----------|
| `create-space` | Creates space from template | On new space |
| `scaffolding-auditor` | Validates completeness, reports coverage | Weekly |

---

## AUDITING

Use `scaffolding-auditor` agent to:
1. Check existence of all listed documents
2. Update status (missing/stub/draft/reviewed/published)
3. Report coverage metrics
4. Flag documents needing human review

---

## Contributing New Document Types

When your team discovers a needed document type:

1. **Create** your space-specific version
2. **Test** that it provides value
3. **PR** to datacore-org adding to SCAFFOLDING.base.md:
   - Document name and path pattern
   - Purpose description
   - Optional: template in `_templates/`

See [DIP-0003](dips/DIP-0003-scaffolding-pattern.md) for details.
