# Datacore v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the 8 architectural upgrades from the 2026-07-29 retrospective as Datacore v2: event-ledger task substrate, job contracts + unified verifier, single config plane, grounded briefings, action loop with co-sign, server-first artifacts, agent consolidation, and executor adapters — each audited, verified, and documented as a DIP.

**Architecture:** A signed, hash-chained, per-writer append-only event log becomes the substrate for task state, shadow accounting, and attestation (upgrade-ready per ENG-2026-0729-016 invariants: append-only, deterministic fold, signatures, conservation, replaceable sequencer). Job contracts + one verifier replace scattered watchdogs. All new code lands inert (nothing rewires live crons) and activates behind env flags in explicit integration tasks.

**Tech Stack:** Python 3.11+, `cryptography` (Ed25519), SQLite (stdlib), PyYAML, pytest. Flat-script + package conventions of `.datacore/lib/`, tests in `.datacore/lib/tests/`.

## Global Constraints

- `~/Data` origin is the PUBLIC repo `datacore-one/datacore`: no secrets, no private keys, no personal data in any tracked file. Private keys live in `~/.datacore/keys/` (outside the repo). `index.db` and derived state are gitignored.
- Event files (`<space>/.datacore/events/<actor>.jsonl`) are per-writer and append-only — the sync-conflict-free property depends on ONE writer per file; never write to another actor's file.
- Deterministic fold: no wall-clock reads, no randomness inside `fold()`/`build_index()`. HLC stamping happens only at append time.
- No behavior change to live crons/daemons until a phase's explicit integration task; new entry points are no-ops unless `DATACORE_V2=1`.
- Dates in any generated doc/DIP: verify day-of-week via `python3 .datacore/lib/date_utils.py dow <date>`.
- Bash in scripts/docs: single-line, chained with `&&`.
- Every task: pytest green before commit; commit messages `feat(v2): ...` / `test(v2): ...`; end each phase with its DIP draft (Draft status — owner ratifies) on a feature branch in `.datacore/dips/` (separate repo).
- New dependency floor: `cryptography>=42` (verified 43.0.3 installed on Mac; box parity checked in Phase 1 Task 9).
- Do not modify org files, `cos_*.sh`, or `datacored` until the phase that explicitly targets them.

```python
"""Hybrid logical clock: sortable stamps, monotonic per actor, no regressions."""
import time

def tick(actor: str, last: str | None = None, _now_ms: int | None = None) -> str:
    now = int(time.time() * 1000) if _now_ms is None else _now_ms
    if last is None:
        pt, c = now, 0
    else:
        lpt, lc, _ = parse(last)
        if now > lpt:
            pt, c = now, 0
        else:
            pt, c = lpt, lc + 1
    return f"{pt:013d}.{c:04d}.{actor}"

def parse(stamp: str) -> tuple[int, int, str]:
    pt, c, actor = stamp.split(".", 2)
    return int(pt), int(c), actor
```
