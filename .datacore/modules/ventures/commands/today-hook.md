## Venture Portfolio Status

For each space with `venture.yaml` present:
1. Run venture-monitor logic (cadence health, budget, hypothesis status)
2. Output a status section per venture
3. Generate org tasks for any overdue cadences

### Output Format

```markdown
## Venture Portfolio

### Forge — Seed
**Cadences:** 4 active, 1 overdue
**Budget:** $2,400 remaining (80% of $3,000)
**Hypotheses:** 2 TESTING, 1 OPEN, 0 VALIDATED

#### Overdue Cadences
- Weekly product review — 3 days overdue (last: 2026-04-06)

#### Active Hypotheses
- **H-001** Etsy SEO titles outperform generic names — TESTING since 2026-03-15
- **H-002** $15 price point maximizes margin/volume — TESTING since 2026-04-01

---

### Datafund — Growth
**Cadences:** 6 active, 0 overdue
**Budget:** €18,500 remaining (74% of €25,000)
**Hypotheses:** 1 TESTING, 3 OPEN, 2 VALIDATED

#### Active Hypotheses
- **H-007** Verity pilot converts 30% of trial users — TESTING since 2026-04-02
```

### Implementation

The venture status is generated by `lib/venture_status.py`:

```bash
python3 .datacore/modules/ventures/lib/venture_status.py --spaces-root ~/Data
```

The cadence runner writes org tasks to the space's `org/inbox.org`:

```bash
python3 .datacore/modules/ventures/lib/cadence_engine.py --run --all-spaces --root ~/Data
```

Both scripts are called by nightshift timers (overnight + `/today` morning run).

### Space Detection

A space is a venture space if `[space-root]/venture.yaml` exists. The hook scans all top-level directories under `~/Data/` matching the pattern `[N]-[name]/`.

### Org Task Format

Overdue cadence tasks are written as:

```org
* TODO [venture] [cadence name] overdue — [N] days
  :PROPERTIES:
  :CREATED: [YYYY-MM-DD]
  :END:
  :venture:cadence:
  Last run: [YYYY-MM-DD]. Due: [YYYY-MM-DD].
```
