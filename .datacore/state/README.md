# State Directory

This directory contains runtime state files for Datacore. All files here are **gitignored** and auto-generated by agents and commands during operation.

## Files

| File/Dir | Purpose | Generated By |
|----------|---------|-------------|
| `execution_log.yaml` | Nightshift task execution history | `ai-task-executor` |
| `hook_state.yaml` | Hook execution state and timestamps | Hook system |
| `structure_version.yaml` | DIP checksums for migration detection | `migration-detector` |
| `sync_history.db` | External sync operation log | Sync adapters |
| `relationships.db` | CRM relationship graph database | CRM module |
| `campaign-state.json` | Campaign tracking state | Campaigns module |
| `knowledge-surfacing.yaml` | Knowledge resurfacing schedule | Learning system |
| `today.log` | Latest /today command output | `/today` command |
| `today.error.log` | Latest /today error output | `/today` command |

## Directories

| Dir | Purpose |
|-----|---------|
| `agents/` | Per-agent runtime state |
| `crm/` | CRM module state |
| `research/` | Research pipeline state |
| `trading/` | Trading module state |
| `whatsapp/` | WhatsApp module state |

## Bootstrapping

State files are created automatically on first use. No manual initialization needed. If a state file is missing, the relevant agent or command will recreate it with defaults.

To reset all state: `rm -rf .datacore/state/*` (preserves this README).
